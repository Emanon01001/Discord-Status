# Discord Status

This project is a Rust application that updates your Discord status based on various activities.

## Features

- Update Discord status with custom messages
- Support for multiple activities
- Lightweight and fast

## Installation

1. Clone the repository:
    ```sh
    git clone https://github.com/yourusername/Discord-Status.git
    ```
2. Navigate to the project directory:
    ```sh
    cd Discord-Status
    ```
3. Build the project:
    ```sh
    cargo build --release
    ```

## Usage

1. Run the application:
    ```sh
    ./target/release/discord-status
    ```
2. Follow the on-screen instructions to set up your activities and status messages.

# ディスコードステータス

このプロジェクトは、さまざまなアクティビティに基づいてディスコードのステータスを更新するRustアプリケーションです。

## 特徴

- カスタムメッセージでディスコードのステータスを更新
- 複数のアクティビティをサポート
- 軽量で高速

## インストール

1. リポジトリをクローンします:
    ```sh
    git clone https://github.com/yourusername/Discord-Status.git
    ```
2. プロジェクトディレクトリに移動します:
    ```sh
    cd Discord-Status
    ```
3. プロジェクトをビルドします:
    ```sh
    cargo build --release
    ```

## 使用方法

1. アプリケーションを実行します:
    ```sh
    ./target/release/discord-status
    ```
2. 画面の指示に従って、アクティビティとステータスメッセージを設定します。
